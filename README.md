# Planificador Académico PUPR

Herramienta para consejeros académicos de la Universidad Politécnica de Puerto Rico: genera planes de estudio por trimestre a partir del currículo y del transcript del estudiante.

**Usar la app:** https://luigito-dev.github.io/planificador-pupr/

Los datos de los estudiantes (transcripts, notas y planes) se procesan y se guardan solo en el navegador de quien la usa; nunca se suben a este repositorio ni a ningún servidor.
